# 通用 AI 图像标注模板

改 `配置.yaml` 里的**接口地址、密钥、模型**，把图片放进 `输入图片`，在 PyCharm 里运行 `标注引擎.py` 即可。
换标注任务只需换 `任务/` 下的 YAML，不用改代码。

---

## 一、在 PyCharm 里跑起来

1. **打开文件夹**：PyCharm → File → Open，选择本文件夹（不要只打开单个 .py 文件）。
2. **选择解释器**：Settings → Project → Python Interpreter，选择 Python 3.10 及以上版本（建议新建虚拟环境）。
3. **安装依赖**：打开 `requirements.txt`，PyCharm 顶部会提示 Install requirements，点击安装；或在终端执行：
   ```
   pip install -r requirements.txt
   ```
4. **填写配置**：打开 `配置.yaml`，只需要改这三项：
   - `接口.地址`：OpenAI 兼容接口地址
   - `接口.密钥`：你的 API Key
   - `接口.模型`：支持图片输入的模型名称
5. **放图片**：把待标注图片放进 `输入图片` 文件夹（第一次运行会自动创建）。
6. **运行**：右键 `标注引擎.py` → Run。

可选参数（填在 PyCharm 运行配置的 Parameters 里）：

| 参数 | 作用 |
| --- | --- |
| `--检查` | 只发一张测试图验证地址/密钥/模型，不处理正式图片 |
| `--任务 任务/检测框.yaml` | 临时切换任务，不改 `配置.yaml` |
| `--配置 其他配置.yaml` | 使用另一份配置文件 |
| `--详细日志` | 输出更详细的调试日志 |

> 不需要命令行启动脚本，PyCharm 直接运行 `标注引擎.py` 即可。

---

## 二、输出结果

所有结果在 `结果/` 下：

| 文件/目录 | 内容 |
| --- | --- |
| `原始JSON/` | 每张图的原始标注结果（原图像素坐标 + 归一化坐标） |
| `掩码/` | 与原图同尺寸的黑白掩码 `*_mask.png` |
| `可视化/` | 每张图的叠加效果图，以及汇总的 `总览图.jpg` |
| `标注结果.json` | COCO 格式标注文件 |
| `处理状态.json` | 本次成功/失败图片统计 |

`清洗后图片/` 保存去掉 EXIF、按最长边缩放后的图片，发送给模型的就是这一份。

---

## 三、换一个标注任务

1. 复制 `任务/黑白mask.yaml`，改名为新任务，例如 `任务/车辆.yaml`。
2. 重点修改：
   - `提示词`：标什么、不标什么、坐标规则、JSON 输出格式
   - `输出字段`：必须和提示词里 JSON 的数组键名一致（例如 `roofs`）
   - `类别名称` / `类别父类`：写入 COCO 的类别信息
   - `属性字段`：模型返回的附加字段及缺省值
   - `显示字段`：可视化时显示哪些属性
3. 修改 `配置.yaml` 的 `任务文件`，或运行时加 `--任务 任务/车辆.yaml`。
4. 不同任务建议使用不同的 `结果目录`，避免结果互相覆盖（引擎发现已有结果的任务名不一致时会自动重新处理）。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| HTTP 401 / 403 | 密钥填写错误、已失效或没有该模型权限 |
| HTTP 400，提示不支持图片 | 当前模型不是视觉模型，换支持图片输入的模型 |
| JSON 被截断 / 解析失败 | 调大 `最大输出Token`；思考型模型要给思考链留足预算 |
| 接口不支持 JSON 模式或思考参数 | 引擎会自动关闭这两个参数重试；仍失败就把 `使用JSON模式` 设为 false、`思考模式` 留空 |
| 单张图超时 | 调大 `超时秒`，或降低 `图片处理.最长边` |
| 中断后想继续跑 | 保持 `跳过已处理: true`，重跑会自动跳过已有 JSON 的图片 |
| 想全部重跑 | 把 `跳过已处理` 设为 false，或删除 `结果目录` |
| 可视化中文变成方框 | 在 `可视化.字体文件` 填系统中文字体，Windows 一般是 `C:/Windows/Fonts/msyh.ttc` |
| 模型返回空数组 | 看 `原始JSON` 和提示词；图片里可能确实没有目标，或模型不认可当前判定标准 |

## 五、分发给别人时

- 发整个文件夹即可，可先删掉 `输入图片/`、`清洗后图片/`、`结果/`、`__pycache__/`。
- **不要带着自己的密钥发出去**：把 `配置.yaml` 里的 `接口.密钥` 改回占位符，或者只发 `配置示例.yaml`，让对方复制为 `配置.yaml` 后填写。
- 密钥一旦外泄，立即到服务商后台作废并重新生成。
- `配置.yaml`、图片目录和结果目录已写入 `.gitignore`，不会被误提交。

## 六、文件说明

```
标注引擎.py         通用标注引擎（一般不用改）
配置.yaml           实际运行读取的配置：地址/密钥/模型/路径
配置示例.yaml       配置备份模板，方便对照
任务/
  黑白mask.yaml       多边形分割任务，输出黑白掩码
  检测框.yaml         目标检测任务，输出检测框
requirements.txt    依赖清单
使用说明.md         本文档
```

运行后自动生成：`输入图片/`、`清洗后图片/`、`结果/`。
