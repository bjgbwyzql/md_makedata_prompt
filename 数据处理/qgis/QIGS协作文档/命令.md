### psql 常用快捷命令

| 命令          | 作用                                                         |
| ------------- | ------------------------------------------------------------ |
| \\l           | 列出所有数据库（小写 L）                                     |
| \\c 库名      | 切换进某个库                                                 |
| \\dn          | 列出当前库里的所有 schema                                    |
| \\dt labels.* | 列出 labels 分区下的所有表                                   |
| \\dx          | 列出已启用的扩展——装完 PostGIS 后用它验证，能看到 postgis 一行 |
| \\conninfo    | 显示当前连的是谁、哪个库                                     |
| \\?           | 快捷命令帮助大全                                             |
| \\q           | 退出 psql                                                    |

**`\d` 家族小抄**（字母决定看哪类对象）：

| 命令                 | 看什么                                                       |
| -------------------- | ------------------------------------------------------------ |
| \\dt                 | 表（tables）                                                 |
| \\ds labels.*        | 序列（sequences）——你两个自增主键背后的“取号机”就藏在这，test_done_fid_seq、test_mask_id_seq |
| \\df labels.*        | 函数（functions）——能看到 labels.touch_updated_at()          |
| \\dv                 | 视图（views），以后才会用到                                  |
| \\d labels.test_done | 不列清单，直接展开单张表的体检单（字段+索引+触发器）         |
